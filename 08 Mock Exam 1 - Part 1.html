A. Short answers (14 points)

A1Warm-up1 pt
Given X of shape (500, 18), i.e. 500 samples with 18 features, create an nn.Linear layer that projects it to 32 features.
Answer and solution
Answer: nn.Linear(18, 32)

in_features = 18 (the batch size 500 doesn't appear); output (500, 32).

A2Warm-up1 pt
Given the input shape (32, 1, 28, 28) and a CNN layer with kernel size 3, stride 1, padding 1 and 32 output channels, what is the output shape?
Answer and solution
Answer: (32, 32, 28, 28)

O = (I − K + 2P)/S + 1 = (28 − 3 + 2·1)/1 + 1 = 27/1 + 1 = 28

A3Warm-up1 pt
For the above operation, how should you write the arguments of nn.Conv2d?
Answer and solution
Answer: nn.Conv2d(1, 32, 3, 1, 1)

(in_channels, out_channels, kernel_size, stride, padding).

A6Warm-up1 pt
An RNN has input size 10 and hidden size 16. What is the shape of a single b?
Answer and solution
Answer: (16,)

Hidden size sets ht, Wh and b; it doesn't depend on the sequence length.

A7Warm-up1 pt
About what fraction of the training rows is out-of-bag for each tree when m is large?
Answer and solution
Answer: About 36.8% (1/e); about 63.2% are in the bootstrap sample.
A8Warm-up1 pt
Why does a random forest use only a random subset of features?
Answer and solution
Answer: To decorrelate the trees. Bootstrapped datasets are similar, so without it every tree would split on the same strong features and they'd make the same mistakes.
A9Warm-up1 pt
What does a leaf predict in a classification tree? In a regression tree?
Answer and solution
Answer: The majority class of its samples; the mean of its targets.
A10Warm-up1 pt
What is the shape of xsamples in the bagging code, for B trees, sample_size rows and n features?
Answer and solution
Answer: (B, sample_size, n).
A11Warm-up1 pt
In which cases does K-means perform badly?
Answer and solution
Answer: Non-spherical clusters (moons, rings) and clusters of very unequal size (or density). Also sensitive to outliers, the starting centers, and unscaled features.

2023 Q6 key: "non-equal sized clusters; non-circular shape".

A12Warm-up1 pt
What do we learn about b and β after maximizing?
Answer and solution
Answer: Sb = βb: b is an eigenvector of the covariance matrix, β is its eigenvalue, and the projected variance equals β.

PCA workshop Q7.

A13Warm-up1 pt
In an RNN, which weights are shared across time steps?
Answer and solution
Answer: All of them: Wx, Wh and b are the same at every step.

Workshop Q2.

A14Warm-up1 pt
What is padding for? What does padding = 1 mean?
Answer and solution
Answer: Adding zeros around the border so edge pixels are used as much as center pixels and the output doesn't shrink. padding = 1 adds a 1-pixel ring of zeros.

B1Exam level7 pts
Given X as [[2, −4], [6, 2], [7, 0], [3, 3], [3, 7]] and y as [1, 1, 0, 1, 0], answer the following. X has 5 samples and two features; superscript (i) is the i-th sample, subscript j the j-th feature.

  3. Given the split x2 < 0, find the total weighted Gini of the children. (2 pts)

Answer and solution
Answer: (1) 12/25 = 0.48 (2) 7/15 ≈ 0.4667 (3) 2/5 = 0.4 (4) x₂ < 0

(1) IG = 1 − (2/5)² − (3/5)² = 1 − 4/25 − 9/25 = 12/25 = 0.48

(2)

  1. x₁ values are [2, 6, 7, 3, 3]. Left (x₁ < 6): samples 1, 4, 5 with y = [1, 1, 0]. Right (x₁ ≥ 6): samples 2, 3 with y = [1, 0].
  2. Gini of the left child: 1 − (1/3)² − (2/3)² = 1 − 1/9 − 4/9 = 4/9 ≈ 0.4444
  3. Gini of the right child: 1 − (1/2)² − (1/2)² = 1 − 1/4 − 1/4 = 1/2 = 0.5
  4. Weighted Gini = (mleft/m)·Ileft + (mright/m)·Iright = (3/5) × 4/9 + (2/5) × 1/2 = 4/15 + 1/5 = 7/15 ≈ 0.4667

(3)

  1. x₂ values are [−4, 2, 0, 3, 7]. Left (x₂ < 0): samples 1 with y = [1]. Right (x₂ ≥ 0): samples 2, 3, 4, 5 with y = [1, 0, 1, 0].
  2. Gini of the left child: 1 − (1/1)² = 1 − 1 = 0
  3. Gini of the right child: 1 − (2/4)² − (2/4)² = 1 − 4/16 − 4/16 = 1/2 = 0.5
  4. Weighted Gini = (mleft/m)·Ileft + (mright/m)·Iright = (1/5) × 0 + (4/5) × 1/2 = 0 + 2/5 = 2/5 = 0.4

(4) Smaller weighted Gini wins: x₂ < 0.

Equation: ht = xt·Wx + ht−1·Wh + b

Step t = 1 (x1 = 2, h0 = [1, 0, 0, −1, −1])

  1. x1·Wx = 2 × [0.5, 0.5, 2, 1, −0.5] = [1, 1, 4, 2, −1]
  2. h0·Wh (h0 times each column of Wh):
    component 1: 1·(−1) + 0·(−3) + 0·2 + (−1)·(−1) + (−1)·0 = 0
    component 2: 1·(−1) + 0·3 + 0·3 + (−1)·0 + (−1)·1 = −2
    component 3: 1·(−2) + 0·(−1) + 0·(−1) + (−1)·3 + (−1)·3 = −8
    component 4: 1·(−2) + 0·1 + 0·(−1) + (−1)·3 + (−1)·2 = −7
    component 5: 1·(−1) + 0·(−1) + 0·1 + (−1)·(−3) + (−1)·(−3) = 5
    → [0, −2, −8, −7, 5]
  3. h1 = [1, 1, 4, 2, −1] + [0, −2, −8, −7, 5] + [1, 1, 1, 0, 1] = [2, 0, −3, −5, 5]

Step t = 2 (x2 = 1, h1 = [2, 0, −3, −5, 5])
