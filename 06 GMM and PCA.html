GMM: the idea in plain words

A Gaussian mixture model says the data was generated by k Gaussian "blobs". Each cluster c has a mean μ(c), a covariance Σ(c) (its spread and tilt) and a mixing weight π(c) (how big a share of the data it owns; the π's sum to 1).

Unlike K-means, GMM makes soft assignments: the responsibility rc(i) is the probability that sample i came from cluster c (each row of r sums to 1). Because every cluster has its own covariance, the blobs can be stretched ellipses and different sizes: exactly the cases where K-means fails.

It is fitted with EM, the same two-step loop as K-means:

  1. E-step: with the current μ, Σ, π, compute every responsibility (Bayes: prior × likelihood, normalized).
  2. M-step: with the responsibilities, recompute every π, μ and Σ as weighted averages.

Repeat until the log-likelihood stops improving. The prediction for a sample is the cluster with the largest responsibility. Because GMM models the density p(x), it can also generate new samples.

GMM formula card

GMM (shapes follow the professor's code)
  • Responsibility: rc(i) = π(c)·N(x(i) | μ(c), Σ(c)) / Σc' π(c')·N(x(i) | μ(c'), Σ(c'))
  • 1-D Gaussian: N(x | μ, σ²) = (1/√(2πσ²))·e−(x − μ)²/(2σ²). In n dimensions: (2π)−n/2|Σ|−1/2 e−½(x − μ)TΣ−1(x − μ).
  • Nc = Σi rc(i) (column sums of r; they add up to m, not to 1).
  • π(c) = Nc/m. μ(c) = (1/Nc) Σi rc(i)x(i). Σ(c) = (1/Nc) Σi rc(i)(x(i) − μ(c))(x(i) − μ(c))T (use the new μ).
  • Objective: maximize the log-likelihood Σi log Σc π(c) N(x(i) | μ(c), Σ(c)).
  • Shapes: means (n, k) in the notebook (one column per cluster); covariances (k, n, n); π (k,); r (m, k); Nc (k,).
  • Initialization (notebook): means = k random samples; every covariance = np.cov(X.T) of the whole data; π = 1/k; r = 1/k.
  • Predict: argmax of r along axis 1. sklearn: GaussianMixture(n_components=k).fit(X).predict(X).

PCA: the idea in plain words

PCA finds new axes for the data. The first axis (principal component) points in the direction where the data varies the most; the second is perpendicular to it and captures the most of what's left, and so on. Keeping only the first n′ axes compresses each sample from n numbers to n′ numbers while losing as little spread (information) as possible.

The math says these directions are the eigenvectors of the data's covariance matrix, and each eigenvalue is the variance along its eigenvector. So PCA is: center the data, compute the covariance, eigen-decompose it, keep the eigenvectors with the largest eigenvalues, and project.

Uses: visualization (to 2-D), faster models, noise removal. Weaknesses: it is linear, and outliers distort it. Scale your features first, or the feature with the biggest units dominates.

PCA formula card

PCA (shapes)
  • Projection: z(i) = BTx(i) ∈ ℝn′; matrix form Z = XB, shape (m, n′). B has shape (n, n′).
  • Steps: (1) center X (subtract each feature's mean); (2) S = XTX/(m − 1) (the derivation uses 1/m; eigenvectors are the same either way); (3) eigen-decompose S = QΛQT; (4) sort eigenvalues from largest; B = the first n′ columns of Q; (5) Z = XB.
  • Shapes: X (m, n), S (n, n), Q (n, n) with eigenvectors as columns, eigenvalues (n,), B (n, n′), Z (m, n′), reconstruction X̂ = ZBT (+ mean): (m, n).
  • Why eigenvectors: maximize bTSb subject to ‖b‖ = 1 (Lagrange) → Sb = βb: b is an eigenvector, β its eigenvalue, and the variance of the projection equals β.
  • 2 × 2 shortcut: for S = [[a, b], [b, d]], λ = (a + d)/2 ± √(((a − d)/2)² + b²); eigenvector for λ ∝ [b, λ − a], then divide by its length.
  • Explained variance ratio: λj/Σλ. Choose n′ so the cumulative ratio reaches, e.g., 95%.
  • Two ways to find eigenvectors: eigen decomposition (np.linalg.eigh) or SVD.
  • sklearn: PCA(n_components=2).fit_transform(X); components_ (rows = eigenvectors), explained_variance_, explained_variance_ratio_, inverse_transform.

PCA worked example: four points by hand

X = [[2, 1], [3, 4], [5, 3], [6, 6]] (m = 4 samples, n = 2 features). Reduce to n′ = 1.

  1. Mean of each feature: [4, 3.5]. Centered data Xc = X − mean = [[−2, −2.5], [−1, 0.5], [1, −0.5], [2, 2.5]]
  2. Covariance S = XcTXc/(m − 1) = (1/3) × [[10, 9], [9, 13]] =
    3.33333
    34.3333
  3. Eigenvalues of [[a, b], [b, d]]: λ = (a + d)/2 ± √(((a − d)/2)² + b²) = 3.8333 ± √(0.25 + 9) → λ₁ = 6.8747, λ₂ = 0.792
  4. Eigenvector for λ₁: solve (S − λ₁I)v = 0 → v ∝ [b, λ₁ − a] = [3, 3.5414]; normalize to length 1: b₁ = [0.6464, 0.763] (the sign is arbitrary: [−0.6464, −0.763] is equally correct). Second component b₂ = [0.763, −0.6464] (perpendicular).
  5. Explained variance ratio of PC1 = λ₁/(λ₁ + λ₂) = 0.8967
  6. Project onto PC1: z = Xc·b₁ = [−3.2003, −0.2649, 0.2649, 3.2003] (shape (4, 1))
  7. Reconstruct: X̂ = z·b₁T + mean = [[1.9314, 1.0581], [3.8288, 3.2979], [4.1712, 3.7021], [6.0686, 5.9419]]

sklearn agrees: explained_variance_ = [6.8747, 0.792], and components_[0] = [0.6464, 0.763] (possibly with the opposite sign).

Common mistakes

  • GMM: normalizing r down the columns. Each row (one sample) sums to 1.
  • GMM: dividing μ by m instead of Nc. The weighted mean divides by the total responsibility of that cluster.
  • GMM: thinking Nc sums to 1. The Nc sum to m; the π sum to 1.
  • PCA: forgetting to center before the covariance and the projection.
  • PCA: taking rows of Q as eigenvectors. In NumPy they are columns (sklearn's components_ stores them as rows).
  • PCA: using np.linalg.eigh's first column as PC1. eigh sorts ascending: PC1 is the last column unless you re-sort.
  • PCA: forgetting that an eigenvector's sign is arbitrary. [0.6, 0.8] and [−0.6, −0.8] describe the same axis.

All the GMM and PCA workshop questions.

How does GMM differ from K-means in initialization?
Answer and solution
Answer: Besides the means (picked like K-means centers), GMM also initializes a covariance per cluster (the data's covariance), the mixing weights π = 1/k, and responsibilities r = 1/k.

"PCA maximizes the variance of the reduced data": in plain words?

Write the GMM EM loop from scratch (NumPy + scipy's multivariate_normal), following the notebook's shapes, and run it on make_blobs.
Answer and solution
Answer: See the reference.
import numpy as np
from scipy.stats import multivariate_normal

def gmm(X, K, max_iter=50, seed=0):
    m, n = X.shape
    rng = np.random.default_rng(seed)
    mean = X[rng.choice(m, K, replace=False)].T          # (n, K)
    cov = np.array([np.cov(X.T) for _ in range(K)])      # (K, n, n)
    pi = np.full(K, 1 / K)                               # (K,)
    for _ in range(max_iter):
        # E-step: r (m, K)
        r = np.column_stack([pi[c] * multivariate_normal.pdf(X, mean[:, c], cov[c]) for c in range(K)])
        r /= r.sum(axis=1, keepdims=True)
        # M-step
        Nc = r.sum(axis=0)                               # (K,)
        pi = Nc / m
        mean = (X.T @ r) / Nc                            # (n, K)
        cov = np.zeros((K, n, n))                        # reset!
        for c in range(K):
            D = X - mean[:, c]
            cov[c] = (r[:, c, None] * D).T @ D / Nc[c]
    return mean, cov, pi, r.argmax(axis=1)

Write PCA from scratch: center, covariance, eigh, sort descending, project to n′ components, and reconstruct. Check it against sklearn on the worked example.
Answer and solution
Answer: See the reference.
import numpy as np

def pca(X, n_components):
    mean = X.mean(axis=0)
    Xc = X - mean
    S = Xc.T @ Xc / (len(X) - 1)                  # (n, n)
    vals, vecs = np.linalg.eigh(S)                # ascending, columns are eigenvectors
    order = np.argsort(vals)[::-1]
    vals, vecs = vals[order], vecs[:, order]
    B = vecs[:, :n_components]                    # (n, n')
    Z = Xc @ B                                    # (m, n')
    X_hat = Z @ B.T + mean                        # back to (m, n)
    return Z, B, vals, X_hat

X = np.array([[2, 1], [3, 4], [5, 3], [6, 6]], dtype=float)
Z, B, vals, X_hat = pca(X, 1)
print(vals, B.ravel(), Z.ravel())

from sklearn.decomposition import PCA
p = PCA(1).fit(X)
print(p.explained_variance_, p.components_, p.transform(X).ravel())   # same up to sign
