The idea in plain words

A feedforward network is a stack of nn.Linear layers with activations (like ReLU) in between. Each nn.Linear(in, out) computes X WT + b: it turns every sample's in numbers into out numbers. With one layer and MSE loss, it is exactly the linear regression you already know, trained with gradient descent.

A convolutional network (CNN) is built for images. Instead of connecting every pixel to every neuron, it slides a small filter (say 3 × 3) across the image and computes a weighted sum at every position. Each filter produces one feature map (it lights up where its pattern appears: an edge, a corner). A conv layer with 16 filters outputs 16 channels.

Pooling shrinks the feature maps (2 × 2 max pooling keeps the largest of every 2 × 2 block, halving height and width). After a few conv + pool blocks, the maps are flattened into one long vector per image and passed to nn.Linear layers that output one score (logit) per class.

Almost every exam question here is about shapes: if you can follow (batch, channels, height, width) through every layer, you can answer it.

Shapes and parameters
  • Image input to a CNN: (batch size, channels, height, width), e.g. (500, 3, 14, 14). Grayscale = 1 channel, RGB = 3, CMYK = 4.
  • nn.Linear(in_features, out_features): input (batch, in) → output (batch, out). weight (out, in), bias (out,). Parameters = in·out + out.
  • nn.Conv2d(in_channels, out_channels, kernel_size, stride=1, padding=0): input (B, Cin, H, W) → (B, Cout, Hout, Wout).
  • Output size: O = ⌊(I − K + 2P) / S⌋ + 1 (round down). Apply it to height and width separately.
  • Same padding (stride 1, output size = input size): P = (K − 1)/2. K = 3 → P = 1; K = 5 → P = 2.
  • Conv parameters = Cin·Cout·K·K + Cout (one bias per filter). PyTorch stores the weight as (Cout, Cin, K, K).
  • MaxPool2d(k, s): same size formula with P = 0; channels unchanged; no parameters. MaxPool2d(2, 2) halves H and W (rounding down).
  • Flatten: (B, C, H, W) → (B, C·H·W). x.view(-1, C*H*W); −1 means "work out this dimension" (the batch size).
  • BatchNorm2d(C): shape unchanged; 2C trainable parameters (γ, β). Dropout(p): shape unchanged; no parameters.
  • Classification loss: nn.CrossEntropyLoss(logits (B, classes), labels (B,)). Regression: nn.MSELoss.
  • Inference: model.eval() (dropout off, batch norm uses running stats) + torch.no_grad() (no gradient tracking).

Worked example 2: the 2023 short answers on shapes

  1. X has shape (2300, 5); project it to 64 features. nn.Linear(5, 64). The 2300 samples are the batch dimension; nn.Linear only cares about the 5. Output (2300, 64).
  2. Input shape of images to a CNN? (bs, ch, h, w): batch size, channels, height, width.
  3. Input (350, 4, 28, 28), kernel 3, stride 1, padding 2, 13 output channels: output shape? O = (I − K + 2P)/S + 1 = (28 − 3 + 2·2)/1 + 1 = 29/1 + 1 = 30, so (350, 13, 30, 30). The batch size stays 350; the channels become 13.
  4. Arguments for nn.Conv2d? nn.Conv2d(4, 13, 3, 1, 2), in the order (in_channels, out_channels, kernel_size, stride, padding). Writing the names is safer: nn.Conv2d(in_channels=4, out_channels=13, kernel_size=3, stride=1, padding=2).
  5. Notebook workshop: (100, 3, 40, 40), K = 3, S = 1, P = 2, 12 output channels. O = (I − K + 2P)/S + 1 = (40 − 3 + 2·2)/1 + 1 = 41/1 + 1 = 42 → (100, 12, 42, 42), from nn.Conv2d(3, 12, 3, 1, 2).

This filter subtracts the right column from the left column, so it responds to vertical edges. In a CNN you don't choose the filter values: they are weights, learned by gradient descent. (Deep learning "convolution" doesn't flip the filter; it's this slide-multiply-add.)

Max pooling 2 × 2 on a 4 × 4 map takes the maximum of each 2 × 2 block, giving a 2 × 2 map. Average pooling takes the mean instead.

Dropout: the notebook vs PyTorch

The notebook describes dropout as zeroing a fraction p of values in training, then multiplying by (1 − p) at test time. PyTorch implements the equivalent "inverted" version: during training the kept values are divided by (1 − p), and in eval mode nothing happens. Both keep the expected value the same between training and testing.

Common mistakes

  • Mixing up nn.Linear's order: it's (in, out), but the weight tensor is stored as (out, in).
  • Forgetting the batch dimension. A CNN input is 4-D; a single image needs .view(1, C, H, W).
  • Forgetting to round down when (I − K + 2P) isn't divisible by S.
  • Changing the number of channels in a pooling layer. Pooling keeps channels; only conv layers change them.
  • Using the wrong channel count in the next conv: conv2's in_channels must equal conv1's out_channels.
  • Computing the flatten size from the input image instead of the last pooled feature map.
  • Forgetting the biases in parameter counts: one per output neuron or per filter.

F1Core
Dropout with p = 0.4 is applied in training mode to x = [5, 2, 8, 1, 4], and the 2nd and 5th values are dropped. (a) What does the notebook's version output in training? (b) PyTorch's inverted dropout? (c) What does each output in eval mode?
Answer and solution
Answer: (a) [5, 0, 8, 1, 0] (b) [8.3333, 0, 13.3333, 1.6667, 0] (c) notebook: x × 0.6 = [3, 1.2, 4.8, 0.6, 2.4]; PyTorch: x unchanged
  1. Dropped values become 0.
  2. PyTorch scales the kept values by 1/(1 − 0.4) = 1/0.6 during training: 5/0.6 = 8.3333, 8/0.6 = 13.3333, 1/0.6 = 1.6667.
  3. At test time the notebook multiplies everything by 1 − p = 0.6; PyTorch does nothing (it already scaled during training).

Answer and solution
Answer: [−1.3416, −0.4472, 0.4472, 1.3416]
  1. Mean = 5; variance = mean of squared deviations = (9 + 1 + 1 + 9)/4 = 5; std = √5 ≈ 2.2361
  2. (x − 5)/2.2361 = [−1.3416, −0.4472, 0.4472, 1.3416]
  3. Then a real BatchNorm layer multiplies by a learned γ and adds a learned β. Shape is unchanged.

H. Short answers (1 point each)

The CNN and FFN workshop questions plus the 2023 ones.
H1Warm-up1 pt
What is the input shape of images to a CNN?
Answer and solution
Answer: (batch size, channels, height, width).

2023 Q11.

H2Warm-up1 pt
What is a feature map?
Answer and solution
Answer: The output of one filter slid over the input: a map of where that filter's pattern appears. k filters → k feature maps (channels).
H3Warm-up1 pt
What are common filter sizes, and why odd and square?
Answer and solution
Answer: 3 × 3 and 5 × 5. Odd so there is a center pixel and symmetric padding; square because images have no preferred direction.

Workshop Q3.

H4Warm-up1 pt
What is padding for? What does padding = 1 mean?
Answer and solution
Answer: Adding zeros around the border so edge pixels are used as much as center pixels and the output doesn't shrink. padding = 1 adds a 1-pixel ring of zeros.

Workshop Q4.

H5Warm-up1 pt
What is stride? Bigger vs smaller stride?
Answer and solution
Answer: How many pixels the filter moves each step. Bigger stride → smaller output and less computation, but coarser; smaller → more detail.

Workshop Q5.

H6Warm-up1 pt
What does nn.MaxPool2d(2, 2) mean and do to the shape?
Answer and solution
Answer: A 2 × 2 window moving 2 pixels at a time, keeping the max of each block: H and W are halved (rounded down), channels unchanged.

Workshop Q8.

H7Warm-up1 pt
What is BatchNorm for?
Answer and solution
Answer: Normalizing each feature within the batch (subtract mean, divide by std, then scale and shift with learned γ, β). It stabilizes gradients and speeds up training; shape unchanged.

Workshop Q9.

H8Warm-up1 pt
What is Dropout for?
Answer and solution
Answer: Randomly zeroing a fraction p of activations during training so the network can't rely on any single unit: it reduces overfitting. Off at inference.

Workshop Q10.

H9Warm-up1 pt
Why X.view(-1, 5*5*16) in ConvolutionalNetwork? What does −1 mean?
Answer and solution
Answer: To flatten the (B, 16, 5, 5) feature maps into (B, 400) vectors for nn.Linear. 5, 5 come from the size formula, 16 from conv2's channels. −1 = infer this dimension (the batch).

Workshop Q11.

H10Warm-up1 pt
Why nn.CrossEntropyLoss and not nn.MSELoss here?
Answer and solution
Answer: It's a classification problem: cross-entropy compares a predicted probability distribution (softmax of the logits) with the true class. MSE is for continuous targets.

Workshop Q12.

H11Warm-up1 pt
Why model.eval() and torch.no_grad() at inference?
Answer and solution
Answer: eval() switches dropout off and makes batch norm use its running statistics; no_grad() skips gradient tracking to save memory and time.

Workshop Q13.

H12Warm-up1 pt
What does torch.manual_seed(42) do?
Answer and solution
Answer: Fixes the random number generator so weight initialization and shuffling are reproducible.

FFN workshop Q1.

H13Warm-up1 pt
What is the purpose of a DataLoader? batch_size? shuffle?
Answer and solution
Answer: It serves the dataset in batches; batch_size = samples per batch; shuffle = reorder the data each epoch.

FFN workshop Q3–5.

H14Warm-up1 pt
What does requires_grad=True on a parameter mean?
Answer and solution
Answer: PyTorch tracks operations on it so .backward() can compute its gradient; optimizers update it.

FFN workshop Q8.

H15Warm-up1 pt
What does grad_fn=<AddmmBackward0> on preds mean?
Answer and solution
Answer: preds was created by a matrix multiply-add (X WT + b); grad_fn is the function autograd will use to backpropagate through it.

FFN workshop Q9.

H16Warm-up1 pt
What is the difference between mse and mse.item()?
Answer and solution
Answer: mse is a 0-dimensional tensor (with gradient history); .item() returns a plain Python float.

FFN workshop Q10.

H17Warm-up1 pt
What is the role of torch.optim.SGD?
Answer and solution
Answer: It updates the parameters with their gradients: w ← w − lr · grad (plus momentum if set).

FFN workshop Q11.

H18Warm-up1 pt
What does xb.to(device) mean?
Answer and solution
Answer: Move the tensor to the GPU (cuda) or CPU so it is on the same device as the model.

FFN workshop Q12.

H19Warm-up1 pt
Why does a CNN need fewer parameters than a fully connected network on images?
Answer and solution
Answer: Weight sharing: one small filter is reused at every position, instead of a separate weight per pixel per neuron.
H20Warm-up1 pt
Which layers have no trainable parameters?
Answer and solution
Answer: ReLU (and other activations), MaxPool/AvgPool, Dropout, Flatten.

J. Build it yourself

J1Exam levelscratch
Write a CNN class for CIFAR-10 (input (B, 3, 32, 32), 10 classes): conv 3→16 (K=3, P=1), ReLU, max pool 2; conv 16→32 (K=3, P=1), ReLU, max pool 2; then Linear to 128, ReLU, Linear to 10. Give the flatten size and the parameter count.
Answer and solution
Answer: Flatten size 32·8·8 = 2048; parameters = 268,650
import torch.nn as nn
import torch.nn.functional as F

class CifarCNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.conv1 = nn.Conv2d(3, 16, 3, 1, 1)    # (B, 16, 32, 32) -> pool -> (B, 16, 16, 16)
        self.conv2 = nn.Conv2d(16, 32, 3, 1, 1)   # (B, 32, 16, 16) -> pool -> (B, 32, 8, 8)
        self.fc1 = nn.Linear(32 * 8 * 8, 128)
        self.fc2 = nn.Linear(128, 10)

    def forward(self, X):
        X = F.max_pool2d(F.relu(self.conv1(X)), 2, 2)

import numpy as np

def conv2d(img, k, stride=1, pad=0):
    img = np.pad(img, pad)                     # zeros around the border
    H, W = img.shape
    K = k.shape[0]
    oh, ow = (H - K) // stride + 1, (W - K) // stride + 1
    out = np.zeros((oh, ow))
    for i in range(oh):
        for j in range(ow):
            patch = img[i*stride:i*stride+K, j*stride:j*stride+K]
            out[i, j] = (patch * k).sum()      # multiply element-wise, add
    return out
