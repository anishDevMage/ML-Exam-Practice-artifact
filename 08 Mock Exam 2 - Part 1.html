A. Short answers (14 points)

A1Warm-up1 pt
Given X of shape (500, 8), i.e. 500 samples with 8 features, create an nn.Linear layer that projects it to 128 features.
Answer and solution
Answer: nn.Linear(8, 128)

in_features = 8 (the batch size 500 doesn't appear); output (500, 128).

A2Warm-up1 pt
Given the input shape (500, 1, 32, 32) and a CNN layer with kernel size 3, stride 1, padding 0 and 12 output channels, what is the output shape?
Answer and solution
Answer: (500, 12, 30, 30)

O = (I − K + 2P)/S + 1 = (32 − 3 + 2·0)/1 + 1 = 29/1 + 1 = 30

For the above operation, how should you write the arguments of nn.Conv2d?
Answer and solution
Answer: nn.Conv2d(1, 12, 3, 1, 0)

(in_channels, out_channels, kernel_size, stride, padding).

A7Warm-up1 pt
Hard vs soft assignment: which does K-means use, and which model uses the other?
Answer and solution
Answer: K-means: hard (each sample in exactly one cluster). GMM: soft (a probability for each cluster).
A8Warm-up1 pt
What is PCA's main weakness?
Answer and solution
Answer: Sensitive to outliers, and limited to linear structure (KernelPCA handles non-linear).
A9Warm-up1 pt
What is an RNN, and what is the essence of the model?
Answer and solution
Answer: A network for sequences that keeps a hidden state; at each step it combines the new input with the previous state using the same shared weights.

Workshop Q1.

A10Warm-up1 pt
Why does the first gradient boosting model have no α?
Answer and solution
Answer: It's the starting point (a constant like the mean), not a correction step.

GB workshop Q7.

A11Warm-up1 pt
What are some differences between AdaBoost and gradient boosting?
Answer and solution
Answer: AdaBoost reweights samples and gives each model its own α from its error; gradient boosting fits each model to the residuals and uses one fixed learning rate.

GB workshop Q1.

A12Warm-up1 pt
What does "bagging" stand for?
Answer and solution
Answer: Bootstrap aggregating: bootstrap datasets + aggregating (voting or averaging) the models.
A13Warm-up1 pt
Why nn.CrossEntropyLoss and not nn.MSELoss here?
Answer and solution
Answer: It's a classification problem: cross-entropy compares a predicted probability distribution (softmax of the logits) with the true class. MSE is for continuous targets.

Workshop Q12.

A14Warm-up1 pt
A fully grown tree reaches 100% training accuracy. Is that good news?
Answer and solution
Answer: Not by itself: it usually means the tree memorized the training set (overfitting). Judge it on validation or OOB data.

B1Exam level7 pts
Given X as [[3, 0], [−2, 0], [−1, 3], [0, 4], [6, 2], [−1, 7]] and y as [0, 1, 0, 0, 1, 0], answer the following. X has 6 samples and two features; superscript (i) is the i-th sample, subscript j the j-th feature.
  1. Find the Gini index of this node. (2 pts)

  3. Given the split x2 < 3, find the total weighted Gini of the children. (2 pts)

Answer and solution
Answer: (1) 4/9 ≈ 0.4444 (2) 5/12 ≈ 0.4167 (3) 2/9 ≈ 0.2222 (4) x₂ < 3

(1) IG = 1 − (4/6)² − (2/6)² = 1 − 16/36 − 4/36 = 4/9 ≈ 0.4444

(2)

  1. x₁ values are [3, −2, −1, 0, 6, −1]. Left (x₁ < 3): samples 2, 3, 4, 6 with y = [1, 0, 0, 0]. Right (x₁ ≥ 3): samples 1, 5 with y = [0, 1].
  2. Gini of the left child: 1 − (3/4)² − (1/4)² = 1 − 9/16 − 1/16 = 3/8 = 0.375
  3. Gini of the right child: 1 − (1/2)² − (1/2)² = 1 − 1/4 − 1/4 = 1/2 = 0.5
  4. Weighted Gini = (mleft/m)·Ileft + (mright/m)·Iright = (4/6) × 3/8 + (2/6) × 1/2 = 1/4 + 1/6 = 5/12 ≈ 0.4167

(3)

  1. x₂ values are [0, 0, 3, 4, 2, 7]. Left (x₂ < 3): samples 1, 2, 5 with y = [0, 1, 1]. Right (x₂ ≥ 3): samples 3, 4, 6 with y = [0, 0, 0].
  2. Gini of the left child: 1 − (1/3)² − (2/3)² = 1 − 1/9 − 4/9 = 4/9 ≈ 0.4444
  3. Gini of the right child: 1 − (3/3)² = 1 − 1 = 0
  4. Weighted Gini = (mleft/m)·Ileft + (mright/m)·Iright = (3/6) × 4/9 + (3/6) × 0 = 2/9 + 0 = 2/9 ≈ 0.2222

(4) Smaller weighted Gini wins: x₂ < 3.
