The idea in plain words

Boosting trains weak models one after another, each one focusing on what the previous ones got wrong, and then combines them. (Bagging, by contrast, trains independent trees in parallel and averages them.)

AdaBoost (classification, labels −1 and +1) gives every training sample a weight. A weak classifier, usually a stump (a depth-1 tree), is trained; the samples it gets wrong have their weights increased, so the next stump concentrates on them. Each stump also gets a vote α: accurate stumps get a big α. The final answer is the sign of the weighted vote.

Gradient boosting (shown for regression) starts with a constant guess, the mean of y. Each new tree is trained to predict the residuals y − ŷ of the current ensemble, and its output is added with a small learning rate α (the same for every tree). Fitting the residuals is gradient descent in "prediction space": for the loss ½(y − h)², the negative gradient with respect to h is exactly y − h.

Formula card (copy this onto your cheat sheet)

AdaBoost (y ∈ {−1, +1})
  • Start: w(i) = 1/m for every sample.
  • Weighted error: εs = Σ w(i)·I(hs(x(i)) ≠ y(i)) / Σ w(i), in [0, 1].
  • Voting power: αs = ½ ln((1 − εs)/εs). ε < 0.5 → α > 0; ε = 0.5 → α = 0; ε > 0.5 → α < 0 (the vote is flipped).
  • Update: w(i) ← w(i)·e−αs·hs(x(i))·y(i), then divide by the sum. Wrong samples are multiplied by eα (bigger), correct ones by e−α.
  • Predict: h(x) = sign(Σs αs·hs(x)).
  • Stop: number of classifiers reached, early stopping on validation, or an error threshold.
Gradient boosting (regression)
  • h0(x) = mean of y (DummyRegressor(strategy="mean")). Classification: DummyClassifier(strategy="most_frequent").
  • Residual: r = y − F(x), the negative gradient of J = ½(y − F)² with respect to F.
  • Fit the next tree hs to the residuals; a regression leaf predicts the mean residual of its samples.
  • Update: F(x) ← F(x) + α·hs(x). Final: h(x) = h0(x) + α·h1(x) + … + α·hS(x).
  • Learning rate α: in (0, 1], the same for every tree (0.1 in the notebook); the first model has no α.
  • Stop: desired number of trees, or when the validation residual stops decreasing.

Worked example 1: the AdaBoost workshop

ŷ = [−1, 1, −1, 1, 1] and y = [1, 1, 1, 1, 1]. m = 5, so every starting weight is 1/5 = 0.2 (the weights sum to 1; each is in [0, 1]). The subscript s is the classifier's number in the sequence.

  1. Misclassified samples (ŷ ≠ y): 1, 3.
  2. ε1 = (sum of their weights) / (sum of all weights) = (0.2 + 0.2) / 1 = 0.4
  3. α1 = ½ ln((1 − ε)/ε) = ½ ln(0.6/0.4) = ½ ln(1.5) = 0.2027
  4. Factor e−α·ŷ·y: correct samples (ŷ·y = 1) get e−0.2027 = 0.8165; wrong samples (ŷ·y = −1) get e0.2027 = 1.2247. Factors: [1.2247, 0.8165, 1.2247, 0.8165, 0.8165]
  5. w × factor = [0.2449, 0.1633, 0.2449, 0.1633, 0.1633], which sums to 0.9798
  6. Normalize (divide by 0.9798): w2 = [0.25, 0.1667, 0.25, 0.1667, 0.1667]

Meaning. ε = 0.4 is the weighted share of mistakes. α = 0.2027 is this stump's voting power: positive but small, because 0.4 is only a little better than guessing. The wrong samples (1 and 3) went from 0.2 to 0.25 and the right ones down to 0.1667, so the next stump will try harder on samples 1 and 3.

Worked example 3: gradient boosting regression by hand

x = [1, 2, 3, 4, 5, 6], y = [5, 7, 6, 12, 14, 16], learning rate α = 0.1, stumps as trees (max_depth = 1), like the notebook.

  1. h0 = mean(y) = 60/6 = 10. Every prediction starts at 10.
  2. Residuals r1 = y − 10 = [−5, −3, −4, 2, 4, 6]. (They always sum to 0 after the mean.)
  3. Fit a regression stump to the residuals: try every midpoint; each leaf predicts the mean residual on its side; keep the split with the smallest sum of squared errors (SSE):

Gradient boosting (scratch, from the notebook)
def fit(X, y, models):
    first_model = DummyRegressor(strategy='mean').fit(X, y)      # h0 = mean(y)
    models_trained = [first_model]
    for model in models:
        residual = y - predict(X, models_trained)                 # grad(y, h) = y - h
        model.fit(X, residual)                                    # next tree fits the residuals
        models_trained.append(model)
    return models_trained

def predict(X, models):
    learning_rate = 0.1                                           # same for every tree
    return models[0].predict(X) + sum(learning_rate * m.predict(X) for m in models[1:])
Trap: the Extended AdaBoost update uses the wrong predictions

In Extended - AdaBoost, after the triple loop that searches for the best stump, the line W = W * np.exp(-clf.alpha * y * yhat) uses yhat, which still holds the predictions of the last candidate tried in the loop, not the best stump's. Recompute it before the update: yhat = np.ones(m); yhat[clf.polarity * X[:, clf.feature_index] < clf.polarity * clf.threshold] = -1.

Common mistakes

  • Using labels 0/1 in AdaBoost. The update e−α·ŷ·y only works with −1/+1 (the notebook converts with np.where(y == 0, −1, 1)).
  • Forgetting to normalize the new weights so they sum to 1.
  • Using log base 10. ln is the natural log (np.log).
  • Giving every gradient boosting tree its own α. One learning rate, shared; and none on h0.
  • Fitting the next gradient boosting tree to y instead of to the residuals.
  • Forgetting that a regression leaf predicts the mean of its residuals, not a class.

G2Core
Show that for J = ½(y − h)², the negative gradient with respect to h is the residual. Why is that the reason "the next tree fits the residuals"?
Answer and solution
Answer: ∂J/∂h = h − y, so −∂J/∂h = y − h: exactly the residual.
  1. ∂J/∂h = ½·2(y − h)·(−1) = h − y.
  2. Gradient descent moves h in the direction −∂J/∂h = y − h.
  3. So the best "step" for each sample is its residual: a tree trained to predict the residuals is a gradient step in function space, and α is its step size.

J1Exam levelscratch
Write AdaBoost from scratch with sklearn stumps (sample_weight) and compare it to AdaBoostClassifier on make_classification data.
Answer and solution
Answer: See the reference.
import numpy as np
from sklearn.tree import DecisionTreeClassifier

class MyAdaBoost:
    def __init__(self, S=50):
        self.S = S

    def fit(self, X, y):                       # y must be -1/+1
        m = len(y)
        w = np.full(m, 1 / m)
        self.models, self.alphas = [], []
        for _ in range(self.S):
            stump = DecisionTreeClassifier(max_depth=1).fit(X, y, sample_weight=w)
            yhat = stump.predict(X)
            e = w[yhat != y].sum() / w.sum()
            a = 0.5 * np.log((1 - e) / (e + 1e-10))
            w = w * np.exp(-a * y * yhat)
            w = w / w.sum()
            self.models.append(stump); self.alphas.append(a)
        return self

    def predict(self, X):
        return np.sign(sum(a * m.predict(X) for a, m in zip(self.alphas, self.models)))

Write gradient boosting regression from scratch as a class with n_estimators, learning_rate and max_depth, and check it against GradientBoostingRegressor.

import numpy as np
from sklearn.tree import DecisionTreeRegressor

class MyGBR:
    def __init__(self, n_estimators=200, learning_rate=0.1, max_depth=1):
        self.S, self.lr, self.depth = n_estimators, learning_rate, max_depth

    def fit(self, X, y):
        self.f0 = y.mean()                               # h0
        F = np.full(len(y), self.f0)
        self.trees = []
        for _ in range(self.S):
            residual = y - F                             # negative gradient of 1/2 (y - F)^2
            tree = DecisionTreeRegressor(max_depth=self.depth).fit(X, residual)
            F = F + self.lr * tree.predict(X)
            self.trees.append(tree)
        return self

    def predict(self, X):
        return self.f0 + sum(self.lr * t.predict(X) for t in self.trees)
