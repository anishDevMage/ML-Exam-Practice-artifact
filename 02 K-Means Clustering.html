The idea in plain words

K-means groups unlabeled samples into k clusters. It is unsupervised: there is no y, only X.

It keeps k centers (centroids) μ1, …, μk and repeats two steps:

  1. Assign (E-step): every sample joins the cluster of its nearest center.
  2. Update (M-step): every center moves to the mean of the samples that joined it.

It stops when the centers stop moving (equivalently, no sample changes cluster), or after a maximum number of iterations. Every iteration can only lower (or keep) the total within-cluster variation W(C), which is why it always stops. But it can stop in a poor solution if it started badly, which is why sklearn runs it several times from different starts (n_init).

You choose k yourself. The elbow method plots W(C) against k and picks the k where the curve stops dropping steeply.

Formula card (copy this onto your cheat sheet)

K-means
  • Squared distance: ‖x(i) − μc‖² = Σj (xj(i) − μc,j)². The square root is optional: the nearest center is the same either way.
  • Assign: c(i) = argminc ‖x(i) − μc‖². Ties go to the lower-numbered center (that is what argmin does).
  • Update: μc = (sum of the samples in cluster c) / (number of samples in cluster c), feature by feature.
  • Stop: centers don't change (no sample moves), or max iterations.
  • Within-cluster variation of cluster c: W(c) = Σi∈c Σj (xj(i) − μc,j)². Total W(C) = Σc W(c) = sklearn's inertia_.
  • Choosing k: elbow of the W(C)-vs-k curve (W always falls as k grows, so don't pick the minimum).
  • Fails on: non-spherical shapes (moons, rings), clusters of very different sizes or densities, outliers, and unscaled features. Depends on the starting centers.
  • Shapes: X (m, n), centers (k, n), labels (m,), distance matrix (m, k).

In the professor's code

The algorithm, with the plotting and printing removed
def kmeans(X, n_clusters):
    m, n = X.shape
    rng = np.random.RandomState(42)
    i = rng.permutation(m)[:n_clusters]       # pick k random samples as the first centers
    centers = X[i]                            # (k, n)
    while True:
        labels = pairwise_distances_argmin(X, centers)    # (m,): nearest center per sample
        new_centers = np.array([X[labels == i].mean(axis=0) for i in range(n_clusters)])
        if np.allclose(centers, new_centers):             # stop when centers stop moving
            break
        centers = new_centers
    return centers

Trap: empty clusters

If no sample is assigned to some center, X[labels == i].mean(axis=0) is the mean of an empty array: NumPy warns and returns nan, and the algorithm breaks. sklearn handles this for you. Picking initial centers from the data (as the code does) makes it rarer.

Scale your features first (StandardScaler) when they have different units: K-means is all distances.

Common mistakes

  • Averaging the distances instead of the coordinates. The new center is the mean of the samples' feature values.
  • Forgetting to square negative differences: (−2)² = 4, not −4.
  • Keeping old distances in iteration 2. Every distance must be recomputed with the new centers.
  • Stopping after the update step when two iterations are asked: iteration 2 needs its own assignment and update.
  • Mixing up which center is μ₁ and which is μ₂. Keep the order the question gives.
  • Choosing the k with the lowest W(C). W(C) always shrinks as k grows (k = m gives 0); look for the elbow.

Write sq_dist(X, C) that returns the (m, k) matrix of squared distances, without loops, using broadcasting. Test on the 2023 data and centers [[1, 1, 1], [3, 3, 3]].
Answer and solution
Answer: [[5, 21], [9, 33], [21, 5], [22, 2]]
import numpy as np

def sq_dist(X, C):
    # X: (m, n) -> (m, 1, n);  C: (k, n) -> (1, k, n);  difference: (m, k, n)
    return ((X[:, None, :] - C[None, :, :]) ** 2).sum(axis=2)   # (m, k)

X = np.array([[-1, 1, 2], [1, -2, 1], [2, 5, 3], [3, 4, 4]])
C = np.array([[1, 1, 1], [3, 3, 3]])
print(sq_dist(X, C))
I2Exam levelscratch
Write kmeans(X, C0, max_iter) from scratch with your sq_dist: assign, update, stop when centers don't move. Return centers, labels and W(C). It must reproduce the 2023 answer.
Answer and solution
Answer: centers [[0, −0.5, 1.5], [2.5, 4.5, 3.5]], labels [0, 0, 1, 1], W(C) = 8.5
def kmeans(X, C0, max_iter=100):
    C = np.array(C0, dtype=float)
    for it in range(max_iter):
        labels = sq_dist(X, C).argmin(axis=1)              # E-step
        newC = np.array([X[labels == c].mean(axis=0) if np.any(labels == c) else C[c]
                         for c in range(len(C))])          # M-step (keep empty centers)
        if np.allclose(newC, C):
            break
        C = newC
    W = sum(((X[labels == c] - C[c]) ** 2).sum() for c in range(len(C)))
    return C, labels, W

C, labels, W = kmeans(X, [[1, 1, 1], [3, 3, 3]])
print(C, labels, W)     # [[0. -0.5 1.5] [2.5 4.5 3.5]] [0 0 1 1] 8.5
