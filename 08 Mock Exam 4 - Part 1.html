A. Short answers (10 points)

A1Warm-up1 pt
Given X of shape (2300, 12), i.e. 2300 samples with 12 features, create an nn.Linear layer that projects it to 64 features.
Answer and solution
Answer: nn.Linear(12, 64)

in_features = 12 (the batch size 2300 doesn't appear); output (2300, 64).

A2Warm-up1 pt
Given the input shape (64, 1, 32, 32) and a CNN layer with kernel size 5, stride 2, padding 1 and 16 output channels, what is the output shape?
Answer and solution
Answer: (64, 16, 15, 15)

O = (I − K + 2P)/S + 1 = (32 − 5 + 2·1)/2 + 1 = 29/2 + 1 = 14.5 + 1 → round down: ⌊14.5⌋ + 1 = 15

A3Warm-up1 pt
For the above operation, how should you write the arguments of nn.Conv2d?
Answer and solution
Answer: nn.Conv2d(1, 16, 5, 2, 1)

(in_channels, out_channels, kernel_size, stride, padding).

A4Warm-up1 pt

Answer and solution
Answer: (4, 3, 3)
A5Warm-up1 pt
In PCA on X of shape (1000, 30) reduced to 2 components, what is the shape of the projection matrix B?
Answer and solution
Answer: (30, 2), i.e. (n, n′)
A6Warm-up1 pt
An RNN has input size 10 and hidden size 5. What is the shape of a single Wh?
Answer and solution
Answer: (5, 5)

Hidden size sets ht, Wh and b; it doesn't depend on the sequence length.

A7Warm-up1 pt
Why does an LSTM layer have 4× the parameters of an RNN layer of the same size?
Answer and solution
Answer: It computes four gate/candidate vectors, each with its own Wx, Wh and biases.
A8Warm-up1 pt
Do decision trees need feature scaling? Why?
Answer and solution
Answer: No. Each split compares one feature to a threshold, so the scale of other features doesn't matter, and rescaling a feature just rescales its thresholds.
A9Warm-up1 pt
When does AdaBoost stop? Three ways.
Answer and solution
Answer: When the number of classifiers is reached, by early stopping on validation, or when an error threshold is reached.

What is the difference between mse and mse.item()?
Answer and solution
Answer: mse is a 0-dimensional tensor (with gradient history); .item() returns a plain Python float.

B. AdaBoost (4 points)

B1Exam level4 pts
AdaBoost. ŷ = [−1, −1, 1, 1, −1] and y = [1, −1, 1, 1, 1], with equal starting weights. Compute (a) the weights, (b) ε, (c) α, (d) the factors e−αŷy, (e) the new normalized weights. What are the new weights trying to achieve?
Answer and solution
Answer: ε = 0.4, α = 0.2027, new w = [0.25, 0.1667, 0.1667, 0.1667, 0.25]; they make the next classifier focus on the misclassified samples.
  1. Misclassified samples (ŷ ≠ y): 1, 5.
  2. ε1 = (sum of their weights) / (sum of all weights) = (0.2 + 0.2) / 1 = 0.4
  3. α1 = ½ ln((1 − ε)/ε) = ½ ln(0.6/0.4) = ½ ln(1.5) = 0.2027
  4. Factor e−α·ŷ·y: correct samples (ŷ·y = 1) get e−0.2027 = 0.8165; wrong samples (ŷ·y = −1) get e0.2027 = 1.2247. Factors: [1.2247, 0.8165, 0.8165, 0.8165, 1.2247]
  5. w × factor = [0.2449, 0.1633, 0.1633, 0.1633, 0.2449], which sums to 0.9798
  6. Normalize (divide by 0.9798): w2 = [0.25, 0.1667, 0.1667, 0.1667, 0.25]

D. PCA (4 points)

D1Exam level4 pts
PCA. X = [[2, 4], [2, 7], [7, 6], [0, 3]]. Center the data, compute the covariance matrix (divide by m − 1), its eigenvalues, the first principal component, and project the data onto it.
Answer and solution
Answer: λ = [10.223, 2.027]; b₁ = [0.9169, 0.3992] (or its negative); z = [−1.0869, 0.1108, 4.2958, −3.3198]
  1. Mean of each feature: [2.75, 5]. Centered data Xc = X − mean = [[−0.75, −1], [−0.75, 2], [4.25, 1], [−2.75, −2]]
  2. Covariance S = XcTXc/(m − 1) = (1/3) × [[26.75, 9], [9, 10]] =
    8.91673
    33.3333
  3. Eigenvalues of [[a, b], [b, d]]: λ = (a + d)/2 ± √(((a − d)/2)² + b²) = 6.125 ± √(7.7934 + 9) → λ₁ = 10.223, λ₂ = 2.027
  4. Eigenvector for λ₁: solve (S − λ₁I)v = 0 → v ∝ [b, λ₁ − a] = [3, 1.3063]; normalize to length 1: b₁ = [0.9169, 0.3992] (the sign is arbitrary: [−0.9169, −0.3992] is equally correct). Second component b₂ = [0.3992, −0.9169] (perpendicular).
  5. Explained variance ratio of PC1 = λ₁/(λ₁ + λ₂) = 0.8345
  6. Project onto PC1: z = Xc·b₁ = [−1.0869, 0.1108, 4.2958, −3.3198] (shape (4, 1))
  7. Reconstruct: X̂ = z·b₁T + mean = [[1.7535, 4.5661], [2.8516, 5.0442], [6.6886, 6.715], [−0.2938, 3.6746]]

F. GMM (4 points)

F1Exam level4 pts
1-D GMM with k = 2. x = [2, 5, 6, 7], μ = [2, 7], σ² = [1, 1], π = [0.5, 0.5]. Perform one E-step and one M-step.
Answer and solution
Answer: r = [[1, 0], [0.0759, 0.9241], [0.0006, 0.9994], [0, 1]]; π = [0.2691, 0.7309], μ = [2.2135, 6.0259], σ² = [0.597, 0.6575]

E-step. For every sample, the Gaussian density under each cluster, times π, then normalize across the row so each row of r sums to 1. Example for sample 1, cluster 1: N(2 | 2, 1) = 1/√(2π·1) · e−(2 − 2)²/(2·1) = 0.3989 · e0 = 0.398942.

M-step.

  1. Nc = column sums of r = [1.0764, 2.9236]
  2. πnew = Nc/m = [0.2691, 0.7309]
  3. μ1 = Σ r1·x / N1 = (1·2 + 0.0759·5 + 0.0006·6 + 0·7) / 1.0764 = 2.2135
  4. μ2 = Σ r2·x / N2 = (0·2 + 0.9241·5 + 0.9994·6 + 1·7) / 2.9236 = 6.0259
  5. σ²1 = Σ r1·(x − μ1)² / N1 = (1·(2 − 2.2135)² + 0.0759·(5 − 2.2135)² + 0.0006·(6 − 2.2135)² + 0·(7 − 2.2135)²) / 1.0764 = 0.597
  6. σ²2 = Σ r2·(x − μ2)² / N2 = (0·(2 − 6.0259)² + 0.9241·(5 − 6.0259)² + 0.9994·(6 − 6.0259)² + 1·(7 − 6.0259)²) / 2.9236 = 0.6575
