0. The toolkit: notation, shapes, derivatives

Notation. X is the data table: m rows (samples) × n columns (features). x(i) is row i, xj is column j, and xj(i) is one cell. y holds the targets, one per row. θ (or w) holds the weights, one per feature.

Shapes rule everything. A matrix product (a, b) @ (b, c) gives (a, c): the inner numbers must match. So X (m, n) @ θ (n,) gives (m,), one prediction per row. XT (n, m) @ error (m,) gives (n,), one number per weight.

Derivatives you need. d/dx of x² is 2x; of ex is ex; of ln x is 1/x. Chain rule: if J depends on h, and h depends on θ, then dJ/dθ = (dJ/dh)·(dh/dθ). Every gradient in this course is the chain rule.

Partial derivative: ∂J/∂θ2 means "treat every other θ as a constant". So for h = θ1x1 + θ2x2, ∂h/∂θ2 = x2.

Learning in one sentence: pick a model h, pick a loss J that measures how wrong it is, then change the parameters to make J small (with gradient descent or a formula).

1. Linear regression and gradient descent

Idea. Predict a number as a weighted sum of the features: ŷ = θ0 + θ1x1 + … + θnxn. Adding a column of 1s to X lets θ0 (the intercept) ride along, so ŷ = Xθ.

Loss. J = ½ Σ (ŷ(i) − y(i))². Squaring makes all errors positive and punishes big ones; the ½ cancels later.

Gradient (chain rule). For one row: ∂J/∂θj = (ŷ − y)·xj. The ½ cancels the 2 from the square, and xj comes from ∂ŷ/∂θj. For all rows, add them up: ∂J/∂θ = XT(ŷ − y).

Update. θ ← θ − α·gradient, where α is the learning rate (a small number like 0.01). The gradient points uphill, so subtracting it goes downhill.

Five steps every iteration: predict ŷ = Xθ → error e = ŷ − y → (loss J = ½Σe², just a score) → gradient XTe → update θ.

Variants. Batch uses all rows per update; stochastic (SGD) uses one row and updates θ before the next row; mini-batch uses a slice (e.g. 50 rows). One epoch = one pass over all rows. Scale features first, or large features (like gold prices) produce huge gradient components.

Worked example
  1. X = [[1, 2], [1, 3]] (first column = intercept), y = [5, 6], θ = [1, 1], α = 0.1.
  2. ŷ = Xθ = [1 + 2, 1 + 3] = [3, 4]; error e = ŷ − y = [−2, −2]; J = ½(4 + 4) = 4.
  3. Gradient XTe = [1·(−2) + 1·(−2), 2·(−2) + 3·(−2)] = [−4, −10].
  4. θ ← [1, 1] − 0.1·[−4, −10] = [1.4, 2]. New ŷ = [5.4, 7.4]: closer to y on average. Loss went down.

2. Regularization and the closed form

Overfitting: a model that fits the training data too closely (often with huge weights) does badly on new data. Regularization adds a penalty on weight size to the loss:

  • Ridge (L2): J + λΣθj². Gradient gets + 2λθ. Shrinks all weights a little.
  • Lasso (L1): J + λΣ|θj|. Gradient gets + λ·sign(θ). Pushes useless weights to exactly 0 (feature selection).
  • Elastic net: a mix of both. λ controls the strength: bigger λ = simpler model.

Closed form (normal equation). Instead of iterating, set the gradient to zero and solve: XT(Xθ − y) = 0 → θ = (XTX)−1XTy. Exact, no learning rate, but needs XTX invertible and becomes slow with many features. For a 2 × 2 matrix [[a, b], [c, d]], the inverse is (1/(ad − bc))·[[d, −b], [−c, a]].

Worked example (closed form)
  1. x = [1, 2, 3], y = [2, 4, 5]. With the intercept column, X = [[1, 1], [1, 2], [1, 3]].
  2. XTX = [[3, 6], [6, 14]], XTy = [11, 25].
  3. det = 3·14 − 6·6 = 6; inverse = (1/6)·[[14, −6], [−6, 3]].
  4. θ = (1/6)·[14·11 − 6·25, −6·11 + 3·25] = (1/6)·[4, 9] = [0.6667, 1.5]: the best line is ŷ = 0.67 + 1.5x.

Every number in these solutions was computed by code. Answers are rounded to 4 decimal places; small differences in the last digit from your calculator are fine.
