How the first half fits together

Almost every model here has the same three parts: a hypothesis h (how it predicts), a loss J (how wrong it is), and a way to find the parameters (gradient descent or a formula).

ModelHypothesisLossGradient / fitting
Linear regressionh = Xθ½Σ(h − y)²Xᵀ(h − y), or θ = (XᵀX)⁻¹Xᵀy
+ Ridge / Lassoh = Xθ+ λΣθ² / + λΣ|θ|+ 2λθ / + λ·sign(θ)
Logistic regressionh = σ(Xθ)−Σ[y log h + (1 − y) log(1 − h)]Xᵀ(h − y)
Softmax regressionH = softmax(XW)−Σ Y log H (one-hot Y)Xᵀ(H − Y)
Gaussian Naive Bayesargmax P(y)·Π N(xj | μ, σ²)–means, stds and priors by counting
Multinomial Naive Bayesargmax log P(y) + Σ count·log P(w | y)–word counts with Laplace smoothing
KNNmajority class of the k nearest–nothing to train: store the data
SVMsign(wᵀx + b)min ½‖w‖² s.t. y(wᵀx + b) ≥ 1dual QP: w = Σαyx (cvxopt)

Notice the same gradient shape XT(prediction − target) for linear, logistic and softmax regression: that's not a coincidence, it comes from pairing each model with its natural loss.

Gradient descent variants

Formula card
  • Batch: θ ← θ − α·XT(Xθ − y), using all m rows per update. The code averages: (1/m)XT(h − y).
  • Stochastic (SGD): one row per update; θ changes between rows, so row 2's prediction already uses the θ updated by row 1.
  • Mini-batch: a slice of rows (e.g. 50) per update; standard in deep learning.
  • Epoch: one pass through all training rows. Loops per epoch: ⌈rows / batch_size⌉ for mini-batch, rows for SGD, 1 for batch.
  • Gradient for one weight: ∂J/∂θj = Σi (h(i) − y(i))·xj(i): errors times feature j, summed over the rows used.
  • Early stopping in the code: stop a fold when the validation loss stops changing (np.allclose).
Trap: np.infty

The Regularization notebook sets self.val_loss_old = np.infty. NumPy 2.0 removed np.infty, so that line raises an AttributeError on a new install. Use np.inf (as the Mini-Batch notebook does).

Regularization and the closed form

Formula card
  • Ridge (L2): J = ½Σ(h − y)² + λΣθj². Gradient adds 2λθ (the code's Ridge.derivation = l·2·theta). Shrinks all weights.
  • Lasso (L1): J + λΣ|θj|. Gradient adds λ·sign(θ). Pushes weights exactly to 0: built-in feature selection.
  • Elastic net: a mix of both (l_ratio of L1, 1 − l_ratio of L2).
  • Bigger λ → simpler model (less overfitting, more risk of underfitting).
  • The code's update: grad = (1/m)XT(ŷ − y) + regularization.derivation(θ).
  • Closed form (normal equation): θ = (XTX)−1XTy. No learning rate or iterations, but needs XTX invertible and costs about n³ for n features.
  • 2 × 2 inverse: [[a, b], [c, d]]−1 = (1/(ad − bc))·[[d, −b], [−c, a]].

Logistic and softmax regression

Formula card
  • Sigmoid: σ(z) = 1/(1 + e−z); σ(0) = 0.5. Predict 1 when h ≥ 0.5, i.e. when θTx ≥ 0.
  • Binary cross-entropy: J = −Σ[y log h + (1 − y) log(1 − h)] (the code divides by m). Natural log.
  • Gradient: XT(h − y), same shape as θ. The notebook trains with SGD (one random row per step, with replacement).
  • Softmax for one sample: pc = ezc / Σk ezk; each row sums to 1.
  • Shapes: X (m, n), W (n, k), XW (m, k), Y one-hot (m, k), gradient XT(H − Y) (n, k). Predict: argmax along axis 1.
  • Cross-entropy: J = −Σ Y log H: only the log-probability of the true class counts.

Naive Bayes and KNN

Formula card
  • Bayes: P(y | x) ∝ P(x | y)·P(y). "Naive": features are independent given the class, so P(x | y) = Πj P(xj | y).
  • Prior: P(y = c) = (samples in class c) / m.
  • Gaussian NB: per class and feature, mean μ and std σ (np.std: divide by the count); P(xj | y) = (1/√(2πσ²))e−(xj − μ)²/(2σ²).
  • Multinomial NB (text): P(w | c) = (count(w, c) + 1)/(total words in c + |V|) with Laplace smoothing (|V| = vocabulary size). Score: log P(c) + Σ count(w)·log P(w | c).
  • Why logs: products of many small probabilities underflow to 0; sums of logs don't.
  • KNN: compute the distance to every training point, take the k nearest (argsort), predict their majority class (np.bincount(...).argmax(), ties → smallest label). Scale features first. Odd k avoids ties in two-class problems.
Trap in the Gaussian NB notebook

In "Let's implement", step 4 computes likelihood1 = gaussian_pdf(X_test, mean[1, :], std[0, :]): class 1 is evaluated with class 0's standard deviations. It should be std[1, :].

Support vector machines

Formula card
  • Predict: sign(wTx + b). Constraint for every training point: y(i)(wTx(i) + b) ≥ 1 (labels −1/+1).
  • Margin width = 2/‖w‖; maximizing it = minimizing ½‖w‖².
  • Support vectors: the points with y(wTx + b) = 1 exactly (α > 0); they alone define w and b.
  • Dual (Lagrange): maximize Σαi − ½ΣΣ yiyjαiαjxiTxj, with αi ≥ 0 and Σαiyi = 0. Then w = Σαiyixi, b = ys − wTxs for a support vector.
  • Soft margin: allow violations ξ, penalized by C. 0 ≤ α ≤ C. Large C → few violations (narrow margin, overfit risk); small C → wide margin, more violations.
  • Kernels replace xiTxj: linear xTz; polynomial (1 + xTz)p; Gaussian/RBF e−‖x − z‖²/(2σ²).
  • cvxopt form: P = H with Hij = yiyjxiTxj (m × m), q = −1, G = −I (and +I for soft margin), h = 0 (and C), A = yT, b = 0.

B6Warm-up1 pt
Why does Lasso produce exactly-zero weights while Ridge only makes them small?
Answer and solution
Answer: The L1 penalty pulls every weight toward 0 with constant force λ·sign(θ), so small weights reach 0 and stay; the L2 force 2λθ shrinks as θ shrinks, so weights get small but rarely exactly 0.
B7Warm-up1 pt
What happens as λ → 0? As λ → ∞?
Answer and solution
Answer: λ → 0: plain linear regression (may overfit). λ → ∞: all penalized weights → 0, a constant model (underfits).
B8Warm-up1 pt
When would you use the closed form instead of gradient descent? When can't you?
Answer and solution
Answer: Small n (few features): exact, no learning rate. Not when XᵀX is singular (duplicate/collinear features, more features than samples), when n is huge (inverting n × n is slow), or for models without a closed form (logistic regression, neural nets).
B9Warm-up1 pt
Polynomial regression with degree 2 on [a, b]: which features does PolynomialFeatures(degree=2) create?
Answer and solution
Answer: [1, a, b, a², ab, b²] (without the 1 if include_bias=False). It is still linear regression, on new features.

Why is Naive Bayes called "naive"?
Answer and solution
Answer: It assumes the features are independent given the class, so the likelihood is a simple product. Rarely true, but it often works well anyway.
D5Warm-up1 pt
Why do we use log probabilities in Naive Bayes?
Answer and solution
Answer: Multiplying many probabilities underflows to 0 on a computer; adding logs is stable and keeps the same winner.

What does Laplace smoothing fix?
Answer and solution
Answer: A word never seen with a class would get probability 0 and zero out the whole product; adding 1 to every count avoids that.

F8Warm-up1 pt
What are support vectors?
Answer and solution
Answer: The training points on the margin (α > 0); only they determine w and b.
F9Warm-up1 pt
What does C control in a soft-margin SVM?
Answer and solution
Answer: The penalty for margin violations: large C → fewer violations, narrower margin; small C → wider margin, more violations (more regularization).
F10Warm-up1 pt
Why do we use the Lagrange dual for SVM?
Answer and solution
Answer: It turns the constrained problem into a QP in α where the data only appears as dot products, so kernels can replace them.
F11Warm-up1 pt
What does a kernel do?
Answer and solution
Answer: Computes a dot product in a higher-dimensional feature space without building the features, so a linear boundary there is non-linear in the original space.
