The idea in plain words

An RNN reads a sequence one step at a time (a day of stock prices, a word) and keeps a hidden state h: a small vector that summarizes everything it has seen so far. At every step it mixes the new input xt with the previous memory ht−1:

ht = f( xt·Wx + ht−1·Wh + b )

The same Wx, Wh and b are used at every time step. That weight sharing is the essence of an RNN: a sequence of length 100 still has just two weight matrices and one bias, applied 100 times. The activation f is usually tanh; exam questions often drop it to keep the arithmetic simple.

Plain RNNs forget long-range information (their gradients shrink as they pass back through many steps). An LSTM adds a cell state c and three gates (forget, input, output) that decide what to keep; a GRU is a lighter version with two gates. The professor's notebook uses nn.LSTM(1, 50) to predict the next day's Apple price from the previous 30 days.

Formula card (copy this onto your cheat sheet)

RNN
  • ht = f(xt·Wx + ht−1·Wh + b), f = tanh (or none, if the question says to ignore it). Start from the given h0.
  • Shapes (n = input size, h = hidden size): xt (n,), ht (h,), Wx (n, h) as given in the exam (the notebook writes (h, n) for the transposed form), Wh (h, h), b (h,).
  • Shared across time: one Wx, one Wh, one b, whatever the sequence length.
  • PyTorch input (default batch_first=False): (seq_len, batch, input_size). Output out: (seq_len, batch, hidden_size). Final hidden hn: (num_layers, batch, hidden_size).
  • Parameters, nn.RNN(n, h): h·n + h·h + 2h (PyTorch keeps two biases). GRU: 3× that. LSTM: 4× that. Second layer: n is replaced by h.
  • Windows: a series of length L with window size w gives L − w (input, target) pairs.
Row form vs column form: write your convention down

The notebook writes ht = f(Wxxt + Whht−1 + b) with Wx of shape (h, n): matrices on the left of column vectors. The 2023 question instead gave Wx as a 1 × 5 row, [[−1, 0.5, 1, 2, 0.5]], and its key says "[−1] dot Wx + [1, 0, 2, −1, 0] dot Wh + b": vectors on the left (row form, what np.dot(h, Wh) does).

For the x term the two forms give the same numbers. For Wh they differ: row form multiplies h by each column of Wh; column form multiplies each row by h. These pages use the row form, matching the 2023 key, and show the column-form answer as well. On your paper, write the equation you used on the first line.

Worked example 3: with tanh

Hidden size 2, x = [[1], [2]], h0 = [0, 0], Wx = [[0.5, −1]], Wh = [[1, 0.5], [−0.5, 1]], b = [0, 0.5]. tanh squashes every component into (−1, 1), so the state can't blow up.

  1. x2·Wx = 2 × [0.5, −1] = [1, −2]
  2. h1·Wh (h1 times each column of Wh):
    component 1: 0.4621·1 + (−0.4621)·(−0.5) = 0.6932

Common mistakes

  • Using Wh's rows when you meant its columns (or the reverse). Decide on row or column form and write it down.
  • Restarting from h0 at every step. h2 uses h1, h3 uses h2.
  • Forgetting b at every step, or adding it only once.
  • Dropping the x term when xt isn't 0, or keeping it when xt = 0.
  • Thinking a longer sequence means more weight matrices. They are shared: always Wx, Wh, b.
  • Saying ht has shape (seq_len, h). One hidden state is (h,); stacking all steps gives (seq_len, h).

What is an RNN, and what is the essence of the model?
Answer and solution
Answer: A network for sequences that keeps a hidden state; at each step it combines the new input with the previous state using the same shared weights.

In an RNN, which weights are shared across time steps?
Answer and solution
Answer: All of them: Wx, Wh and b are the same at every step.

What are the shapes of xt, ht, Wh, Wx and b?

Why do plain RNNs struggle with long sequences?
Answer and solution
Answer: Vanishing (or exploding) gradients: backpropagating through many steps multiplies by Wh again and again.
H5Warm-up1 pt
What does an LSTM add to fix it?
Answer and solution
Answer: A cell state plus forget, input and output gates that control what is kept, written and exposed.

Why does an LSTM layer have 4× the parameters of an RNN layer of the same size?

What is the role of the activation (tanh) in an RNN?

What is h0 usually set to in practice?

import numpy as np

def rnn_forward(xs, h0, Wx, Wh, b, act=None):
    h = np.array(h0, dtype=float)
    hs = []
    for x in xs:                                   # one time step at a time
        h = np.atleast_1d(x) @ Wx + h @ Wh + b     # row form; column form: Wx @ x + Wh @ h + b
        if act == "tanh":
            h = np.tanh(h)
        hs.append(h)
    return np.array(hs)                            # (seq_len, hidden)

h0 = [1, 0, 2, -1, 0]
Wx = np.array([[-1, 0.5, 1, 2, 0.5]])
Wh = np.array([[0, -3, 2, -2, 3], [1, -1, -2, 3, 0], [-3, 2, 1, -1, -3],
               [2, -2, 3, 0, 1], [-1, 3, -3, 2, -2]])

import torch, torch.nn as nn

class PriceLSTM(nn.Module):
    def __init__(self, input_size=1, hidden_size=50, output_size=1):
        super().__init__()
        self.lstm = nn.LSTM(input_size, hidden_size)
        self.linear = nn.Linear(hidden_size, output_size)

    def forward(self, seq):                               # seq: (30,)
        out, _ = self.lstm(seq.reshape(len(seq), 1, -1))  # (30, 1, 50)
        out = self.linear(out.view(len(seq), -1))         # (30, 1)
        return out[-1]                                    # last step only
