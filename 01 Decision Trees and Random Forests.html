The idea in plain words

A decision tree classifies a sample by asking it a chain of yes/no questions. Every question has the same form: "is xj < t?" for one feature xj and one threshold t. "Yes" sends the sample to the left child, "no" sends it to the right child. When it reaches a leaf, the tree answers with that leaf's majority class.

Training is choosing the questions. At a node, the algorithm tries every feature and every candidate threshold. For each candidate it measures how mixed the two children would be, using the Gini index. It keeps the question whose children are least mixed (lowest weighted Gini), then repeats the same search inside each child. A node stops splitting when it is pure, or when no question makes it purer.

The weakness: a tree that keeps splitting until every leaf is pure memorizes the training data, so it overfits. Two fixes: limit the tree (max_depth, min_samples_split), or average many different trees.

Bagging builds many trees, each on a bootstrap sample: m rows drawn with replacement from the m training rows, so some rows repeat and others are left out. The trees vote. A random forest is bagging plus one more trick: each tree (in sklearn, each split) only looks at a random subset of q features, so the trees don't all ask the same questions. The rows a tree never saw are its out-of-bag (OOB) rows, a free validation set.

Formula card (copy this onto your cheat sheet)

Decision tree
  • Gini of a node: IG = 1 − Σc pc2, where pc = (samples of class c in the node) / (samples in the node)
  • Range: 0 (pure, best) to 1 − 1/C (all C classes equally mixed, worst). Two classes: 0 to 0.5. Three classes: 0 to 0.667.
  • Weighted Gini of a split: (mleft/m)·Ileft + (mright/m)·Iright. Smaller is better.
  • Candidate thresholds: sort the feature's distinct values; use the midpoint of each consecutive pair. Values 2, 3, 10, 19 → 2.5, 6.5, 14.5.
  • Rule: xj < t goes left; xj ≥ t goes right. A value equal to t goes right.
  • A split is used only if its weighted Gini is lower than the node's own Gini. Otherwise the node becomes a leaf.
  • Leaf prediction: the majority class of the samples in it.
  • Entropy (alternative): H = −Σ pc log2 pc, range 0 to log2C (0 to 1 for two classes).
Bagging and random forests
  • Bootstrap: draw m rows with replacement from the m training rows; repeat B times → D1, …, DB; train one tree on each.
  • Pasting = the same thing without replacement.
  • Random forest = bagging + each tree only uses q random features. Rule of thumb: q = √n (classification), q = n/3 (regression).
  • Final prediction: majority vote (classification) or average (regression).
  • OOB rows of a tree = rows not drawn for it. P(a row is OOB) = (1 − 1/m)m → 1/e ≈ 0.368 for large m.
  • Validation in a random forest: OOB score (each tree is tested on its own OOB rows; the professor averages the per-tree accuracies).
  • Feature importance (mean decrease in impurity): for every split on feature j, add (mnode/m)·(Inode − weighted Ichildren); normalize so the importances sum to 1; average over trees.

Trap 1: the list aliasing bug (it changes the 2023 answer)

sample_per_class_right = sample_per_class_parent does not copy the list. Both names point to the same list, so after the first feature the "right" counts are used up, and the second feature starts with wrong (even negative) counts. Run verbatim on the 2023 data, the notebook's function returns (1, 4.5) with a "weighted Gini" of −0.4, which is impossible. The correct answer is (1, 3.5) with 4/15. Fix: sample_per_class_right = sample_per_class_parent.copy(). With one feature (the notebook's demo) the bug never shows.

Trap 2: fit() uses the global X and y

Inside fit(Xtrain, ytrain, ...), the lines indices_left = X[:, feature] < threshold and X[indices_left], y[indices_left] use the notebook's global X, y instead of Xtrain, ytrain. It works in the demo by luck. In your own code, use the function's arguments.

Trap 3: stats.mode(...)[0][0] on new SciPy

In the bagging and random forest code, stats.mode(predictions)[0][0] was written for old SciPy. From SciPy 1.11, stats.mode drops the extra axis, so [0][0] returns one number instead of one prediction per test sample. Use stats.mode(predictions, axis=0, keepdims=False).mode.

Also worth knowing: in the RandomForest class, with_no_replacement=True is the default, so RandomForest(B=5, bootstrap_ratio=0.8) actually draws 84 of the 105 rows without replacement: that's pasting, and every tree has exactly 21 OOB rows. The list named oob_idx holds the rows that were drawn; the OOB rows are X[~mask]. The trees themselves are sklearn trees with max_depth=2 and max_features="sqrt".

Common mistakes

  • Dividing by the total number of samples instead of the number in the child. In a child with 3 samples, p = count/3.
  • Forgetting the weights: the split's Gini is not (Ileft + Iright)/2; each child is weighted by its share of samples.
  • Putting a sample with xj = t on the left. The rule is strict: xj < t goes left.
  • Thinking larger Gini is better. Smaller is purer, and the best split has the smallest weighted Gini.
  • Drawing a bootstrap sample without repeats. With replacement, repeats are allowed (and common).
  • Applying q to rows. q = √n is the number of features a tree may use, not the number of samples.

import numpy as np

def gini(counts):
    m = sum(counts)
    return 1.0 - sum((c / m) ** 2 for c in counts)

def find_split(X, y, n_classes):
    m, n = X.shape
    if m <= 1:
        return None, None
    parent = [np.sum(y == c) for c in range(n_classes)]
    best_gini = gini(parent)                  # a split must beat the parent
    feature_ix, threshold = None, None
    for feature in range(n):
        order = np.argsort(X[:, feature])
        x_sorted, y_sorted = X[order, feature], y[order]
        left = [0] * n_classes
        right = parent.copy()                 # .copy() fixes the notebook's bug
        for i in range(1, m):                 # i samples on the left
            c = y_sorted[i - 1]
            left[c] += 1
            right[c] -= 1
            if x_sorted[i] == x_sorted[i - 1]:
                continue                      # can't cut between equal values
            w = (i / m) * gini(left) + ((m - i) / m) * gini(right)
            if w < best_gini:
                best_gini = w
                feature_ix = feature
                threshold = (x_sorted[i] + x_sorted[i - 1]) / 2
    return feature_ix, threshold

    feature, threshold = find_split(X, y, n_classes)
    if feature is not None:
        go_left = X[:, feature] < threshold          # the function's own X, y
        node.feature_index, node.threshold = feature, threshold
        node.left = fit(X[go_left], y[go_left], n_classes, depth + 1, max_depth)
        node.right = fit(X[~go_left], y[~go_left], n_classes, depth + 1, max_depth)
    return node

def predict(x, node):
    while node.left is not None:
        node = node.left if x[node.feature_index] < node.threshold else node.right
    return node.predicted_class

tree = fit(Xtrain, ytrain, 2)

import numpy as np
from sklearn.tree import DecisionTreeClassifier

def bootstrap(X, y, B, rng):
    m = X.shape[0]
    idx = rng.integers(0, m, size=(B, m))           # with replacement
    oob = [np.setdiff1d(np.arange(m), idx[b]) for b in range(B)]
    return X[idx], y[idx], oob                       # (B, m, n), (B, m), list of arrays
